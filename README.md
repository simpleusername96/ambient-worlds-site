# Ambient Worlds

자율적으로 변화하는 절차적 풍경을 조용히 감상하는 미니멀 플레이어입니다. 이 앱은 GPT-5.6과 GPT-6와의 협업만으로 구현되었습니다.

- **Journey** — 변화하는 풍경을 따라 계속 달리는 여정
- **Stillwater** — 물, 빛, 식물과 물고기가 살아 움직이는 고요한 연못

비슷한 ambient-world 앱을 만들고 싶은 분들에게 작은 도움이 되기를 바랍니다.

---

A minimal player for quietly watching autonomous procedural worlds. This app was built entirely through collaboration with GPT-5.6 and GPT-6.

- **Journey** — an endless drive through changing landscapes
- **Stillwater** — a quiet living pond shaped by water, light, plants, and fish

We hope it helps others create ambient-world experiences of their own.
