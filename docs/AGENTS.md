# docs/AGENTS.md

## Scope

- These rules govern only `docs/**`.
- Keep the compact current project contract and authority map in `PROJECT.md`.
- Write maintained agent-facing project knowledge in English and requesting-user guides in Korean unless requested otherwise.
- Keep active task progress, temporary research, raw validation output, and public-site copy out of project documentation.
- Replace stale current claims in their canonical owner; retain superseded rationale only when it has concrete future value and is clearly historical.
- Preserve identifiers, paths, URLs, commands, source-language evidence, public copy, and licensing facts exactly.
